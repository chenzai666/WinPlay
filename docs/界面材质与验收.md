# 界面材质与验收

本轮按《WinPlay 全界面 macOS 风格改造方案》的渐进式重构方向实现：保留 .NET 8、WinUI 3、Windows App SDK 1.7 和现有设备发现、音频、镜像及快捷键逻辑，统一视觉资源与窗口材质。

## 材质分工

| 界面 | 实现 | 回退方式 |
| --- | --- | --- |
| 托盘设备面板 | `Window.SystemBackdrop` 配合 `DesktopAcrylicController` | 系统策略回退；不支持时使用主题纯色 |
| 音量 HUD | 同一套 Acrylic，保持无焦点显示和预创建 | 同上 |
| 设置及快捷键 | `MicaBackdrop`，透明标题栏与侧栏 | 不支持时使用主题纯色 |

所有窗口只使用一套系统背景。根面板保持透明，不再叠加深色遮罩，也不再混用 DWM 背景类型和未公开的窗口合成接口。玻璃通透度直接调整 Acrylic 的色调与亮度参数；它不改变系统模糊半径。系统关闭透明效果、启用节能或高对比度时，由系统控制器应用相应策略。

Mica 主要参考桌面壁纸，适合长期使用的设置窗口；托盘与 HUD 使用 Acrylic 体现窗口后方内容的磨砂效果。设置窗口采用现有的通用、音频、快捷键、关于四个分类；设备选择继续放在托盘面板。

## 主题与兼容

- 新增“跟随系统 / 浅色 / 深色”，同时作用于已创建的各窗口。保留独立的字体颜色选项，可选择自动、黑色、深灰、白色、粉色、蓝色；原有六位颜色配置在启动时继续生效。
- 外观选择保存到 `%APPDATA%\WinPlay\appearance-theme.txt`。
- 保留 `card-glass.txt` 与 `card-opacity.txt`；`card-text.txt` 继续读写字体颜色，选择自动时写入 `auto`，浅深色主题恢复各自默认字色；高对比度使用系统颜色。
- Acrylic 使用 Thin 变体，通透度 90 对应色调不透明度 0.10、亮度不透明度 0.02，100 时两者为 0 并保留背景模糊。控制器使用独立配置跟踪主题与高对比度，避免隐藏、失焦时修改 WinUI 管理的默认配置对象。Windows App SDK 1.7 的不透明度刷新问题按微软 issue #10717 做颜色提交处理。
- 设备状态与音量绑定保持原样。卡片增加选中、悬停和按下反馈。
- HUD 数值即时更新，内容淡入淡出为 150ms；系统材质随窗口显示或隐藏，未使用分层窗口透明度。
- 托盘显示为 180ms、关闭为 150ms，尊重 Windows 关闭动画的设置。
- 设置窗口及 HUD 将逻辑尺寸按 DPI 换算为物理尺寸；HUD 每轮显示时重新定位。托盘与 HUD 使用系统非客户区圆角并隐藏额外描边，不再叠加独立 XAML 外框。

## 构建验证

优先使用仓库的 GitHub Actions CI，在 Windows runner 中构建 WinUI 程序、执行现有 Core 测试并生成自包含验收包 `WinPlay-test-win-x64`。同时生成包含发布文件 SHA-256 清单的小型界面更新包 `WinPlay-ui-update-win-x64`，可在逐文件核对运行库后更新已有安装。本轮不升级 SDK，不发布正式版本标签。

需要手动复现构建时，可在安装 .NET 8 SDK 的 Windows 环境执行：

```powershell
dotnet build src/WinPlay.App/WinPlay.App.csproj -c Release -p:Platform=x64
dotnet test tests/WinPlay.Core.Tests/WinPlay.Core.Tests.csproj -c Release
```

## 人工验收

1. 正常退出旧版后，从独立目录启动验收包，确认托盘面板能显示现有设备；先不要覆盖原安装目录。
2. 在彩色壁纸和有文字的窗口前分别打开设备面板，确认有真实背景模糊，文字清晰。
3. 调整玻璃通透度到 0、50、100，再多次关闭和打开面板，观察材质保持一致。
4. 依次切换浅色、深色、跟随系统，检查托盘、设置和 HUD 的文字与控件配色。跟随系统时再切换 Windows 主题。
5. 切换玻璃开关，确认关闭时为可读的纯色面板，重新开启后恢复 Acrylic。
6. 在 Windows 中临时关闭透明效果、开启高对比度或关闭动画，检查相应回退；验证后恢复原设置。
7. 连接音箱，连续调节音量、静音并在 HUD 正在消失时再次按键，确认无抢焦点、提前隐藏或反馈延迟。
8. 在 100%、150%、200% 缩放与多显示器环境检查设置窗口、面板和 HUD 的位置及文字裁切。
9. 核对设备发现、重连、音频持续传输、镜像与快捷键保存，以及登录启动不弹面板的行为。

Windows 10 的窗口圆角、Mica 支持与 Windows 11 存在差异，按运行环境使用系统材质或纯色回退。视觉与真实设备验收结果应单独记录。

## 材质诊断

需要定位系统回退时，可在启动前设置 `WINPLAY_UI_LOG_PATH` 为本任务专用日志路径。该可选日志仅记录控制器状态、主题、激活及高对比度配置和材质参数，不记录设备或音频内容；默认关闭。
