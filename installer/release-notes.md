## WinPlay 0.1.5

补齐 macOS 风格方案中剩余的窗口轮廓、快捷键键帽和交互动效。

### 改进

- 音量 HUD 改为真正的胶囊形，统一裁剪玻璃底材与内容，去除外层直角残留。
- 设备与设置窗口使用 18 逻辑像素圆角，随窗口大小与 DPI 更新轮廓。
- 快捷键拆成独立键帽，点击后保留原有组合键捕获、直接输入、保存与重复校验。
- 设备卡片悬停为 150ms、选中变化为 180ms，按钮按压缩放为 100ms；关闭系统动画或高对比度时即时反馈。
- 保留字体与强调色独立设置，自动强调色跟随 Windows；仅设置窗口的玻璃底材随强调色着色。
- 保留设备发现、音频传输、镜像及快捷键注册逻辑。

### 安装

- x64：`WinPlay-0.1.5-win-x64-Setup.exe`。
- ARM64：`WinPlay-0.1.5-win-arm64-Setup.exe`。
- 同时提供便携 ZIP 和发布文件 SHA-256 清单。
- 支持当前用户覆盖安装，原有配置位于 `%APPDATA%\WinPlay`；安装前退出旧版，选择原安装目录。

系统关闭透明效果或启用节能、高对比度时，材质按 Windows 策略回退。多显示器及 Windows 10 的实际效果仍需在相应环境验收。
