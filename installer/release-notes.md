## WinPlay 0.1.4

本版集中修正界面材质、主题切换与设置控件一致性。

### 修复与改进

- 修复浅色、深色与跟随系统切换时的材质回调异常。
- 恢复字体颜色设置，字体与强调颜色可独立调整；保留原有颜色配置。
- 自动强调色读取 Windows 当前强调色，并响应系统颜色变化。
- 仅设置窗口的玻璃底材随强调色着色；设备面板和音量 HUD 保持中性磨砂。
- 调整通透度映射，修复设备面板及 HUD 的重复外框与多余客户区高度。
- 统一所有设置页的按钮、下拉框和快捷键输入框，使用半透明填充及一致的尺寸、圆角和交互状态。
- 深色设置页保留暗色材质基底，提高亮背景下的文字可读性。
- 增加材质、主题与设置页面的独立诊断入口，默认正常启动不生成材质日志。
- 同步应用和安装包版本为 0.1.4，并按 x64 / ARM64 区分安装包架构。

### 安装

- x64：`WinPlay-0.1.4-win-x64-Setup.exe`。
- ARM64：`WinPlay-0.1.4-win-arm64-Setup.exe`。
- 两种架构均提供对应便携 ZIP 和发布文件 SHA-256 清单。
- 安装包支持当前用户覆盖安装，原有用户配置保存在 `%APPDATA%\WinPlay`。
- 已安装旧版时，请先退出托盘程序，再安装到原目录。

构建与自动测试通过后发布。实际界面效果及真实音频设备行为由安装后的桌面验收确认。
